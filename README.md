## Projects

### [DevOps Project 01 — Java 3-Tier trên AWS](https://github.com/ducnghiaaa/nghiand224/tree/projects/devops/DevOps-Project-01)

Đưa một ứng dụng Java Spring Boot lên kiến trúc 3 tầng trên AWS, tự động hoá toàn bộ bằng Terraform, Packer và GitHub Actions — không một thao tác tay nào từ lúc push code tới lúc app chạy.

Điểm nhấn: sửa 18 lỗi thật trong bản gốc (trong đó có lỗi khiến `terraform apply` không thể chạy), bỏ bastion host thay bằng SSM Session Manager, và đo chi phí thật giữa NAT Gateway và NAT instance.

`Terraform` · `Packer` · `AWS` · `GitHub Actions` · `Java` · `Spring Boot`
